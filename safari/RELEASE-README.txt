No Shorts for YouTube — Safari for macOS
========================================

Xcode is not required. This zip is a prebuilt app from GitHub Actions.

Русский
-------
1. Распакуйте архив. Перетащите NoShortsForYouTube.app в «Программы», если хотите.
2. Если macOS пишет, что приложение не удалось проверить:
   Control-клик (правый клик) по NoShortsForYouTube.app → Открыть → Открыть.
   Или в Терминале: xattr -cr NoShortsForYouTube.app
3. Запустите приложение один раз — так Safari его увидит. Окно можно закрыть.
4. Safari → Настройки (⌘,) → Дополнения → «Показывать функции для веб-разработчиков».
5. Вкладка «Разработка» → включите «Разрешить неподписанные расширения».
   Флажок сбрасывается каждый раз, когда вы полностью закрываете Safari.
6. Вкладка «Расширения» → включите No Shorts for YouTube.
7. Откройте youtube.com и разрешите доступ к сайту, если Safari спросит.

English
-------
1. Unzip. Optionally drag NoShortsForYouTube.app into Applications.
2. If macOS says the app cannot be verified:
   Control-click NoShortsForYouTube.app → Open → Open.
   Or in Terminal: xattr -cr NoShortsForYouTube.app
3. Launch the app once so Safari can see the extension. You can close the window.
4. Safari → Settings (⌘,) → Advanced → “Show features for web developers”.
5. Developer tab → enable “Allow unsigned extensions”.
   This checkbox resets every time you fully quit Safari.
6. Extensions tab → enable No Shorts for YouTube.
7. Open youtube.com and allow access if Safari asks.
